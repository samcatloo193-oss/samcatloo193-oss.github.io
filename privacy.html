Privacy policy

PM Assistant is a private tool used by a single project manager. It connects to the owner's Google account to read, create and complete Google Tasks and to create report documents and photos in Google Drive, only in files it creates itself.

Google user data is used only to provide these features to the account owner. It is not shared with anyone, not sold, not used for advertising, and not used to train AI models. The app's use of Google data follows the Google API Services User Data Policy, including its Limited Use requirements.

Data is stored on private servers controlled by the owner and can be deleted at any time. Contact: samcatloo193@gmail.com
